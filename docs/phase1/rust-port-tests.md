# Rust port: the Python tests and their Rust tests

The Rust port of the phase 0 analysers (pull request krcm0209/lazymkv#2; design
`docs/superpowers/specs/2026-10-13-rust-port-design.md`, section 5) ported every test function of the seven
`scripts/phase0/test_*.py` files one for one: 213 tests (`test_analysis.py` 13, `test_audio_dataset.py` 64,
`test_audio_similarity.py` 36, `test_decisions.py` 26, `test_exp11_tracks.py` 5, `test_ocr_compare.py` 20,
`test_subtitle_text.py` 49). The Python was deleted after commit `d3a754d`; read a Python test with
`git show d3a754d:scripts/phase0/<file>`.

Each row gives the Python test as `<file>::<class>::<method>`, the Rust test as `cargo test --workspace -- --list`
prints it, the file that defines the Rust test's `fn`, and the task of the port's implementation plan that ported it.
The rows follow the Python files in name order and each file in line order. `crates/dev/tests/port_mapping.rs` checks
this table: 213 rows numbered 1 to 213, exactly the Python tests in that order (by the SHA-1 of their list), the count
per file, every Rust test named once and defined in the file its row names, and no placeholder left.

The tests the port added beyond these (the Python spellings, the in-memory tree, the goldens, `decide`, the cases of
the plan's Review Focus) are not listed here; `cargo test --workspace -- --list` lists every test.
